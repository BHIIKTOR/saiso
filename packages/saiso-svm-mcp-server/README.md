# @saiso/svm-mcp-server

First-party SAISO SVM MCP server with canonical Solana/SVM parity operations for generated SAISO projects.

## Install

```bash
npm install @saiso/svm-mcp-server@rc
```

The package also exposes a binary:

```bash
saiso-svm-mcp-server --help
```
