# @saiso/plugin-sdk

Type contracts for SAISO plugin authors.

## Install

```bash
npm install @saiso/plugin-sdk@rc
```

## What It Provides

- plugin manifest and capability shapes
- runtime integration contracts
- shared types used by first-party and third-party SAISO plugin packages

Use this package when building a plugin that should be loaded by SAISO tooling or by a SAISO-compatible runtime.
