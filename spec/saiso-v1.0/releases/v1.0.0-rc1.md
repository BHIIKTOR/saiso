## Included in RC1

1. Active runtime/server support is `evm|svm`.
2. Payment-aware MCP tool invocation implemented for EVM and SVM orchestrators.
3. x402 + MPP payment adapters, parsing, policy, and receipt persistence are included.
4. ERC-8004-aligned identity/trust model and trust-aware routing are included.
5. CI gates include typecheck, core tests, and staging payment smoke checks.
6. Legacy docs and inactive package assets are archived under `spec/old-saiso/`.
7. Publish pipeline includes release validation, pack/install smoke, and core->CLI sequencing.
